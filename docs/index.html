The problem

Given a headline and a news article body, classify their relationship as agree, disagree, discuss, or unrelated.

This is a stance-classification problem, not automated fact checking. The predicted relationship does not determine whether a claim is true.

ML workflow

Headline + article
Text normalization
TF-IDF + n-grams
Classifier
Evaluation

What the project demonstrates

Data preparation

Joining headline/body records, class encoding, normalization, train/test separation, and reusable preprocessing.

Model comparison

Experiments with regularized Logistic Regression, Random Forest, Gradient Boosting, and an early neural-network prototype.

Evaluation

Accuracy, classification reports, confusion matrices, tuning experiments, and a modernized focus on macro-F1 and per-class performance.

Engineering judgment

The original 2020 notebooks are preserved while technical debt and modernization decisions are documented transparently.

Run it for free

No cloud account, hosted endpoint, or commercial API is required.

git clone https://github.com/StavroK/MtySaturdayAI2020.git
cd MtySaturdayAI2020
pip install -r requirements.txt
streamlit run app.py

The Streamlit app can train the modernized TF-IDF + Logistic Regression baseline directly from the repository data and then classify new headline/article pairs locally.

Why preserve the 2020 version?

The project is presented as an engineering evolution rather than rewritten history: the original notebooks show the experimentation process, while the modern code demonstrates reproducibility, testing, governance, and maintainability.

Original

Notebook-driven experimentation, several ML families, manual tuning, and TensorFlow 1.x-era neural code.

Modernized

Reusable pipeline, local inference, Streamlit demo, CI tests, model card, and a documented roadmap.
